TEMANDOR Dokumentasi ♥ Dukung Buka aplikasi

Dokumentasi

Temandor adalah aplikasi sketsa ducting & ventilasi untuk teknisi lapangan: gambar denah, rangkai duct, cek kesalahan, export ke DXF untuk AutoCAD. Gratis dan open source, jalan di browser, data tersimpan di perangkatmu sendiri.

Mulai cepat

  1. Di beranda klik Proyek baru, isi nama dan satuan duct (inch atau mm).
  2. Buka menu Elemen di kiri, seret Indoor ducted (FCU) ke dalam ruangan.
  3. Tekan D, klik ujung supply FCU, lalu klik titik-titik belokan. Elbow dipasang otomatis. Ketik angka + Enter untuk panjang yang pas, Enter lagi untuk selesai.
  4. Seret Diffuser ke ujung duct, isi debitnya di panel Properti.
  5. Klik Export → DXF. Layer ikut, siap dibuka di AutoCAD.

Semua tersimpan otomatis di browser. Untuk pindah perangkat atau cadangan, export .json lalu buka lagi lewat Buka file .json di beranda.

Workspace

Menu kiri berisi kategori. Klik untuk membuka panelnya, klik lagi untuk menutup.

ElemenSemua komponen: ruangan siap pakai (kotak, L, T, U), arsitektur, equipment, duct, fitting, diffuser. Seret ke kanvas, atau klik lalu klik di kanvas. Ada kolom cari.
AlatAlat gambar: jalur duct D, ruangan kotak K, ruangan bebas P, partisi W, ukur U, coretan tangan B.
TeksJudul, subjudul, teks biasa. Langsung muncul di tengah layar dan bisa diketik.
AIAsisten AI yang bisa menggambar, mengubah, dan mengecek sketsa. Lihat Asisten AI.
LayerTampil/sembunyikan dan kunci layer.
ProyekSatuan, skala gambar, gantungan otomatis, tema kanvas, total debit per unit.

Panel Properti muncul di kanan saat ada komponen yang dipilih. Toolbar kecil melayang di atas pilihan untuk aksi cepat (putar, cermin, kunci, duplikat, hapus), klik kanan untuk menu lengkap. Kanan bawah: Pilih, Geser, dan zoom. Tab menutup semua panel (mode fokus).

Di HP/tablet, menu kiri pindah ke bawah layar dan panel muncul dari bawah.

Ruangan & arsitektur

  • Ruangan kotak K: seret dua sudut, atau klik sudut pertama lalu ketik 6x4 + Enter (meter).
  • Ruangan bebas P: klik tiap sudut. Klik titik awal, Enter, atau klik kanan untuk menutup. Cocok untuk bentuk L, T, dan custom.
  • Edit bentuk: pilih ruangan, seret titik ■ atau sisi ●. Klik ganda ● menambah titik, klik ganda ■ menghapus titik. Toolbar ruangan punya tombol bentuk siap pakai.
  • Pintu, jendela, bukaan menempel ke dinding terdekat, memotong garis dinding, dan ikut saat ruangan digeser. Pintu: M balik engsel, R balik arah buka.
  • Partisi W bisa digambar bersambung. Kolom, tangga, lift, shaft dicek terhadap duct: duct yang menabrak memunculkan warning. Duct yang menembus dinding ditandai kotak bobokan.
  • Klik ganda nama ruangan atau teks untuk mengubahnya langsung di kanvas.

Duct & sambungan

  • Komponen yang ditaruh dekat ujung duct otomatis menempel, berputar, dan ikut ukuran ujung itu. R mengganti arah.
  • Titik sambung komponen terpilih: hijau = tersambung, merah = terbuka.
  • Debit dihitung dari diffuser ke unit (FCU/fan), tampil di menu Proyek.
  • Gantungan dipasang otomatis tiap jarak tertentu (atur di menu Proyek).

Warning

Temandor mengecek gambar terus-menerus. Warning tidak menghalangi simpan atau export, hanya pengingat.

Ujung terbukaDuct/fitting belum tersambung. Sambungkan atau pasang end cap.
Ukuran beda tanpa transisiDua ukuran berbeda bertemu langsung. Tambah transisi.
Sistem tercampurDuct supply (SA) tersambung ke exhaust (EA).
Duct menabrakDuct menabrak kolom, tangga, atau lift. Menembus dinding tidak dianggap salah (ditandai bobokan).
Debit belum diisiDiffuser/grille belum punya debit.

Arahkan kursor ke tanda ! untuk melihat alasannya, klik untuk memilih komponennya. Daftar lengkap ada di tombol warning kanan bawah.

Asisten AI

Menu AI di editor menghubungkan Temandor dengan Claude (Anthropic). Tulis permintaan biasa, misalnya "tambah ruang rapat 6x5 m di kanan dengan pintu dan 2 diffuser" atau "cek gambar ini dan jelaskan warning-nya". AI membaca gambar lalu mengubahnya langsung. Setiap langkah AI bisa di-undo dengan Ctrl+Z.

Cara menghubungkan

  1. Buat kunci API di platform.claude.com (perlu akun dan saldo API).
  2. Di editor buka menu AI, tempel kuncinya, klik Hubungkan.
Privasi & biaya. Kunci disimpan di browser ini saja dan hanya dikirim ke api.anthropic.com. Isi gambar dikirim ke Anthropic saat kamu bertanya. Pemakaian ditagih ke akun API-mu. Jangan pakai fitur ini di komputer umum; hapus kunci lewat ikon kunci di panel AI.

Yang bisa dilakukan AI

Server MCP

Temandor punya server MCP supaya Claude Desktop, Claude Code, atau aplikasi AI lain yang mendukung MCP bisa membuat dan mengubah proyek Temandor. Server bekerja pada file .json di satu folder (default ~/Temandor). Hasilnya dibuka di editor lewat Buka file .json, dan proyek dari editor bisa di-export ke folder itu.

Syarat: Node.js 18+. Tanpa npm install, tanpa dependensi.

Claude Code

claude mcp add temandor -e TEMANDOR_DIR=/path/folder/proyek -- node /path/temandor/mcp/server.js

Claude Desktop

Tambahkan ke claude_desktop_config.json, lalu buka ulang Claude Desktop:

{
  "mcpServers": {
    "temandor": {
      "command": "node",
      "args": ["/path/temandor/mcp/server.js"],
      "env": { "TEMANDOR_DIR": "/path/folder/proyek" }
    }
  }
}

Tool yang tersedia

list_projectsDaftar file proyek di folder.
create_projectBuat proyek baru (bisa proyek contoh dengan demo: true).
export_dxfExport proyek ke .dxf di sebelah file-nya.

Plus semua aksi asisten AI di atas, dengan parameter tambahan file. Contoh permintaan ke Claude: "Buat proyek Temandor 'Gudang A' satuan mm, gambar ruangan 12x8 m, FCU di tengah, dan duct ke 4 diffuser, lalu export DXF."

Kontribusi

Temandor open source. Tanpa build step: HTML, CSS, dan JavaScript biasa.

# jalankan lokal (pilih salah satu)
npx serve app
python -m http.server -d app 5179

# tes logika inti + server MCP
node app/test.js
  • app/js/geom.js: tipe komponen, bentuk, grip.
  • app/js/model.js: proyek, sambungan, validasi.
  • app/js/tools.js: aksi gambar untuk AI & MCP.
  • app/js/editor.js, ai.js: editor dan asisten AI.
  • mcp/server.js: server MCP (stdio).

Laporan bug dan ide fitur sangat membantu. Tulis jelas langkahnya, lampirkan file .json proyek kalau bisa.

Dukung Temandor

Temandor gratis untuk semua teknisi. Kalau aplikasi ini membantu pekerjaanmu, dukunganmu membiayai pengembangan, server, dan waktu untuk fitur baru.
